# Homebrew tap for Gobbler

Install the unsigned macOS preview:

```sh
brew install --cask --no-quarantine orchislabs/gobbler/gobbler
```

Upgrade later releases with:

```sh
brew upgrade --cask gobbler
```

Gobbler for Mac supports Intel and Apple Silicon Macs running macOS Monterey or newer. The source remains in the private Groundhog repository; this tap contains distribution metadata only.
